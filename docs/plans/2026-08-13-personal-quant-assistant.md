## 1. 这台助手是干什么的

本机、单用户、模拟盘。每天做且只做五件事：

1. **盯盘**：行情、雷达、账户、异常，开口之前答案已在。
2. **复现**：论文或明确假设 → 可证伪因子/策略，收据说话。
3. **回测**：真数据、可复现实验命名空间，一次一收据。
4. **模拟盘每天跑**：只有已登记、已测试的因子/策略自动跑信号和模拟成交。
5. **看效果**：P&L、回撤、诚实失败写进明早摘要。失败假设要留下，明天不许装作没死过。

不是：发布级 Web Chat 产品、公开 composer、第三条研究厂、LLM 每天辩论下单、实盘。

## 2. 三档自动（防再跑偏的合同）

| 档 | 自动吗 | 例子 |
|---|---|---|
| A. 值班 | **必须自动** | 摘要、雷达、已挂策略的信号/估值/模拟成交、异常箱 |
| B. 新研究 | **你开口，或每周一个固定槽** | 复现一篇论文、挖一条表达式。五分钟 worker **禁止发明**新周期 |
| C. 评价 | **必须自动** | 试运行仓盈亏、回测对照、失败原因进摘要 |

「没上实盘所以权限放到最开」只适用于 **A 和 C**：模拟观察不要被发布仪式或 live 级 kill switch 挡住。  
它不适用于：LLM 改注册表、未登记因子进常驻模拟、任何 live 路径。

## 3. 一张脸，三本账

用户只看见 `/hermes` 一张桌：

- 安全是否挡住模拟观察
- 要你处理的（试运行仓异常、研究失败）
- 对话（五个动词）
- 最近结论（结果或诚实失败）

三本账，不是三套产品：

| 账 | 里面有什么 | 不是什么 |
|---|---|---|
| 值班账 | 摘要、雷达、新闻 | 不是独立「晨报产品」 |
| 研究账 | 论文复现、表达式挖掘、Qlib 对照，都是**来源** | 不是 D-33 厂 + D-34 厂 |
| 模拟账 | 已登记策略 + 限额试运行仓 | 不是按研究来源拆开的两套袖 |

Hermes 对外只暴露五个动词。每个动词一份收据，模型散文不能把 Run 标成成功：

1. 盯盘  
2. 复现这篇  
3. 回测这个  
4. 挂到模拟盘  
5. 今天结果  

Chat 是这五个动词的入口，不是第四套工作台。Discord 继续当独立 Hermes 通道；不要做临时网页 chat、Discord 桥、直连 Hermes 作曲家。

## 6. 红线（下次写代码时看不到就会再跑偏）

- `live_trading_enabled=false`。任何因子、试运行仓、收据都没有 live 升级操作。
- 常驻模拟只跑**已登记、已测试**的因子。候选文件、模型散文、ticker 像不像，都不能进每天跑。
- 新研究禁止由五分钟 worker 发明。没有 owner 需求或每周槽，只维护已挂策略。
- 模型说搜了网 / 回测过 / 成交了，必须有无正文收据；没有就失败，不许 `mark_succeeded`。
- 不重放已经 apply 过的正式库 migration（028–033 等）。新库 `quantplatform_coo` 从 001 顺序来。
- 不改部署镜像 `data/_runtime/agent-v02-work/`。不自动推 `main`。
- 手工 Scene-B 和任何 **live** 资格仍走 Gate 1/2/3。纸面每天跑不走这三道人闸。
- 四只 ETF 上的好看回测不是横截面结论。扩大宇宙是研究账的事，不是另开产品。

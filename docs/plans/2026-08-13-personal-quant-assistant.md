## 1. 这台助手是干什么的

本机、单用户、模拟盘。每天做且只做五件事：

1. **盯盘**：行情、雷达、账户、异常，开口之前答案已在。
2. **复现**：论文或明确假设 → 可证伪因子/策略，收据说话。
3. **回测**：真数据、可复现实验命名空间，一次一收据。
4. **模拟盘每天跑**：只有你**挂上**的因子/策略自动跑信号和模拟成交。双引擎通过只进「已验证候选」，不等于挂上。
5. **看效果**：P&L、回撤、诚实失败写进明早摘要。失败假设要留下，明天不许装作没死过。

不是：发布级 Web Chat 产品、公开 composer、第三条研究厂、LLM 每天辩论下单、实盘。

## 2. 什么自动、什么算你已授权

值班、已挂上的模拟策略、评价：**始终自动**。没上实盘，这三件事不要被发布仪式或 live 级 kill switch 挡住。

研究分两截，禁止合成一句：

| 你做了什么 | 助手最多自动做到哪 | 默认停在哪 |
|---|---|---|
| 发来**论文、链接、截图、书面策略说明** | 读材料 → 代码 → 双引擎回测（平台回测器 + Qlib） | **已验证候选**。要进每天跑，须你说「挂上」，或你事先写明「过了就挂」 |
| 给一条还有效的**研究方向**（「持续挖美股量价反转」） | 提案或跑研究链；**同时最多 1 个作业** | 仍停在已验证候选。方向**不是**全权委托找材料、写码、过了自己挂仓 |
| 发来**视频** | 先抽规则。多数停下来问你 | 不构成第 4 步完成定义，不做视频 intake 主路径 |
| 什么都没给 | 禁止发明周期 | 只维护已挂策略 |

没有授权：五分钟 worker 不得发明研究作业。  
「过了就挂」必须是那一次材料或那一条方向上的明文，不能从「发了论文」推出来。

提取不出可证伪公式、股票池你没给、或对不上收据：停下来问你，或诚实失败。禁止用模型散文冒充「读过 / 回测过」。禁止用视频口播编一条因子再进候选。

纸面成交闸对**已挂上**的仓放开（kill switch 不再顺手冻死观察）。  
叙事闸仍关：模型散文、编股票池、无收据、口播编因子，都不算授权。  
「权限放到最开」仍不适用于：未挂上的因子进常驻模拟、LLM 直接改注册表、任何 live 路径。

## 3. 一个产品，不是一个页面

这是**一个助手**，不是三套厂。不是「只剩 `/hermes` 四个格子」。

- **聊天是遥控，不是第四套工作台**：形态是**本地 owner 的一条受管 Hermes 会话流**——自由输入、模型自选工具、事事有收据，不是「派研究/挂上」两个表单的白名单包装。常用动作仍是查三本账、派研究、挂上、暂停已挂仓；选中某条候选/仓只是把该 ID 附进下一轮上下文。公开 composer 与公开 `chat_write_ready` 仍关，这条流只属于本机 owner。
- **平台页是手，继续一等**：因子实验室、回测器、模拟盘、雷达、持仓地图都留着。聊天调它们，不取代它们。深页从收据钻进去，不是首页上的第二套厂。
- **三本账**：值班账（摘要/雷达/新闻）、研究账（材料、作业、**已验证候选**）、模拟账（**已挂上**的策略 + 限额试运行仓）。来源不再决定跑哪本账。候选不是挂上。

通道（目标，不是第 2 步已交付的样子）：

- 隔离预览 `:3002` 纸面页上的「聊天遥控」只核对两条命令，**不是** Hermes 网页已经能说话。
- `/hermes` 公开 composer 仍关。不要做临时网页 chat、Discord/TUI 桥、直连 Hermes 作曲家。
- Discord 走本机已装 Hermes。`hqa-remote` 装进 live Hermes 之前，Discord 仍可能走旧 D-33 enqueue（过了就挂）。装 skill 是第 3–4 步之后的通道对齐，不是另开产品。
- 微信是后接适配，不挡主线。

## 6. 红线（下次写代码时看不到就会再跑偏）

- `live_trading_enabled=false`。任何因子、试运行仓、收据都没有 live 升级操作。
- 常驻模拟只跑**已挂上**的因子。已验证候选、候选文件、模型散文、ticker 像不像，都不能进每天跑。
- 双引擎通过只进**已验证候选**。进每天跑必须另有「挂上」，或该次材料/方向上明文「过了就挂」。
- **挂上必须绑定该候选的源码 / artifact digest**（双引擎收据或等价 CAS）。禁止 `StrategyConfig.create` 一条与候选无关的演示策略充「已挂上」。
- 持续方向最多同时 1 个研究作业，默认停在候选，不得自己找材料、过了自己挂仓。
- 没有授权：禁止发明研究作业，只维护已挂策略。没有「每周槽」。
- 视频不是第 4 步完成条件。先抽规则，多数停下来问。禁止口播编因子进候选。
- 模型说搜了网 / 读了论文 / 看了视频 / 回测过 / 成交了，必须有无正文收据；没有就失败，不许 `mark_succeeded`。
- 公式或股票池抽不出来：停下来问你，或诚实失败。禁止推断宇宙。
- 不重放已经 apply 过的正式库 migration（028–033 等）。新库 `quantplatform_coo` 从 001 顺序来。
- 不改部署镜像 `data/_runtime/agent-v02-work/`。不自动推 `main`。
- 手工 Scene-B 和任何 **live** 资格仍走 Gate 1/2/3。纸面每天跑不走这三道人闸。
- 四只 ETF 上的好看回测不是横截面结论。扩大宇宙是研究账的事，不是另开产品。

设计第 6 部分：实施切片、旧页面迁移与验收

目标不是一次性“大重写”，而是每一阶段都能看到真实进展、独立验收和安全回滚。现有线框只验证信息架构，绝不会直接翻译成生产界面。

0
视觉定稿

专业前端 Agent 重新设计

先审计真实页面、设计 token 和数据形态；给出 2–3 个高保真方向，再完成可点击的全状态原型。当前 brainstorm 线框不能复制进生产代码。

用户可见成果
1440 / 1280 / 768 / 390 四档真实尺寸；首页、会话、结果、审批均可走查。
1
安全与合同

先修不能带入新工作台的底层风险

修正候选根目录；Gate 2 review lock 绑定 candidate metadata + source digest；回测和 promotion 复核摘要。冻结 Hermes Sessions / Runs / SSE / approval / stop 与 provider capability 合同。

硬门槛
摘要变化必定 stale；聊天文本永远不能触发 Gate。
2
真实对话

完成第一条端到端竖切

专用 Hermes profile/API、同源 BFF、会话 provider 选择、发送/流式/停止/重连、幂等与离线缓存接通。先只开放普通对话和安全只读能力。

用户可见成果
网页里真的与本地 Hermes 对话；每个 Run 显示实际 provider / model。
3
研究任务

自然语言变成可恢复的 HQA Task

新增 append-only research task ledger；实现计划卡、plan hash、Gate 1、Run attempts、结构化步骤、停止与恢复。根路由在此阶段正式默认进入 /hermes。

用户可见成果
提出研究目标 → 看懂计划 → 确认 → 实时看到真实执行步骤。
4
结果与审批

重做统一结果页和审批中心

因子证据、回测曲线/订单/持仓/归因、实验比较、源码/审计进入 Hermes 路由；接入 Gate 2/3、stale/digest 状态与“待我确认”。自动化首页只展示结论和异常。

用户可见成果
不离开 Hermes 就能理解结果、继续讨论并完成正式审批。
5
旧页退场

功能等价后再隐藏、重定向、删除 UI 壳

先移除导航入口但保留旧路由回滚；深链、结果详情和审批 E2E 全部通过后设置兼容重定向，最后删除旧表单组件。后端引擎、API、产物和安全 Gate 全部保留。

禁止伪进度
不能通过先删页面来宣称整合完成。
6
硬化交付

故障、迁移、全量测试与真实本地体验

验证 Hermes 离线、SSE 断线、数据库不可用、provider quota/fallback、partial result、stale approval 和 rollback；启动前后端、Docker PostgreSQL 与 Hermes，完成明确授权的本地 smoke。

最终成果
文档、迁移、服务启动方式和项目现状同步，旧数据零丢失。
旧 URL 如何迁移
/factor-lab→/hermes?intent=factor-research /factor-lab/[runId]→/hermes/results/factors/[runId] /backtest→/hermes?intent=backtest /backtest/[runId]→/hermes/results/backtests/[runId] /experiments→/hermes/results/experiments /agent-studio→/hermes/approvals
动态详情 URL 必须保留原 run ID；书签、前进后退、多语言路由、离线与 404 均要单独验收。
自动化验证：不消耗真实额度
  • Fake Hermes Server + 可控 SSE / approval / stop / quota fixtures
  • HQA ledger 原子写、损坏恢复、attempt 与 operation idempotency
  • candidate digest、Gate stale、promotion TOCTOU 回归测试
  • React 状态目录、Playwright 全流程、固定视口视觉回归
  • Hermes 离线、重连、partial、数据库故障和显式 fallback

CI 和常规测试不得调用真实 Grok / Codex，也不得触发 paper/live 交易路径。

人工验收：真实但有边界
  • 用户先批准高保真，再批准生产壳，再批准功能等价
  • 本地 Grok 与 Codex 各完成一条明确授权的普通对话 smoke
  • 完成一条 proposal-only 研究链路与 Gate 1/2/3 演练
  • 确认 paper_only、live disabled、kill switch 与人工 Gate 未被绕过
  • 前端 console 0 error；键盘、对比度、长文本与移动端可用

最后才移除旧 UI 组件；禁用新工作台即可回滚，原有产物和引擎不受影响。

专业前端硬门槛：全状态高保真必须先经你确认；实现后由另一名前端/UX reviewer 在真实接入、统一结果、旧页退场三个节点独立复审。无裁切、无横向溢出、无“微卡片墙”，正常自动化压缩，异常与待办优先。

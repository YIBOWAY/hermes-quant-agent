设计第 6 部分：可见进展、安全切流、最后删除

复核后的交付顺序采用“先扩展、再切流、最后收缩”。页面可以很早看见，但执行能力、审批和旧页删除必须逐级通过门槛。

专业设计

高保真先行，不照抄当前线框

专业前端 Agent 审计真实代码、截图、token 和数据密度，给出 2–3 个高保真方向；再做贯通首页、会话、结果、审批的可点击全状态原型。

你的 Gate
确认 1440 / 1280 / 768 / 390 四档视觉与交互后，才进入生产组件。
1
安全基线

修候选真相源与摘要绑定

统一真实目录 data/agent_run/agent/candidates；审计旧目录，只有摘要一致才合并，冲突不覆盖。candidate 目录不可覆写；Gate 2 绑定有序文件清单与 exact-bytes SHA-256；无摘要旧批准一律 legacy_unbound、要求重审。

先于一切执行
一次性回测和 promotion 都必须重算摘要；聊天“同意”无效。
2
可见外壳

先做真实尺寸的只读 Hermes 首页

用现有 9H feed 和 hermetic fixtures 实现首页、会话、任务、审批、结果路由，以及 loading / empty / degraded / offline 状态；此时不接写端，不启动研究。

尽早可见
视觉、响应式和无障碍通过后，/ 即默认进入 /hermes。
3
真实对话

浏览器真正连接本地 Hermes

专用 profile/API → 同源 BFF → Sessions / Runs / SSE / stop；会话锁定 Grok 或 Codex，显示实际 provider / model、显式 fallback、幂等与断线恢复。浏览器不拿 bearer。

首条竖切
只开放普通对话和安全只读能力；绝不 fallback 到旧 /api/agent/tasks。
4
任务与历史

HQA 账本 + 统一只读结果先落地

新增 versioned append-only Task / Attempt / Event ledger；BFF/PG 只做映射和缓存。先迁历史 factor / backtest / experiment 的读取、深链、图表和审计证据，不开放新研究。

功能等价
旧 run ID 可直接打开新结果；结果不依赖聊天文本才能理解。
5
受控研究

逐条开放自然语言研究链路

计划卡 → Gate 1 → HQA / 平台确定性执行 → Gate 2 摘要校验 → 一次性研究回测 → Gate 3 diff review。先 factor，再 experiment，最后 backtest；每条都是独立 tracer bullet。

安全门槛
领域 Gate 与 Hermes 命令审批分离；等待 Gate 时结束当前 Run，批准后新 attempt。
6
逐页切流

临时 307、独立开关、逐页验收

agent-studio 最先，其次 factor-lab，然后 experiments，backtest 最后。每页先改所有消费者和深链，再移导航入口；出问题只回滚 redirect/flag。

保留不删
API、CLI、async status/cancel、artifact、图表与三道安全 Gate 全部保留。
7
硬化删除

两轮冷启动与故障演练后才物理删除

Hermes 断线恢复、平台/HQA 重启、历史深链、DB 故障、quota/fallback、partial/stale、前后端+Docker DB+Hermes 服务启动全部通过；旧 E2E 改成新路径 parity 断言。

最终收缩
最后删除旧 page/form，再将兼容 redirect 固化；旧数据零丢失。
旧入口与动态深链
/agent-studio→/hermes/approvals /factor-lab→/hermes?intent=factor-research /factor-lab/[runId]→/hermes/results/factors/[runId] /experiments→/hermes/results/experiments /backtest→/hermes?intent=backtest /backtest/[runId]→/hermes/results/backtests/[runId]
必须同步改造 dashboard recent runs、factor handoff、experiment “Send to Backtest”、Sidebar CTA；locale、query、run ID、书签和浏览器前进后退均需保留。

  • Fake Hermes + 录制 SSE / approval / stop / quota fixtures

人工：真实但有边界
  • 高保真、生产壳、真实接入、功能等价四次明确评审
  • Grok / Codex 各一条用户授权的低成本普通对话

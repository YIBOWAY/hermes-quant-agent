密钥与网络

浏览器不直连 Hermes

API key 只存在平台服务端；Hermes 仅监听 127.0.0.1，不开放浏览器 CORS。

能力边界

首版只开纯对话与只读研究

不开放通用 patch、文件写入、cron 管理、delegation 或浏览器自动化。

审批边界

两类审批绝不混淆

Hermes 命令审批不等于 Gate 1 公式确认、Gate 2 源码批准或 Gate 3 promotion diff 审查。

降级规则：Hermes 离线时，今日概览、历史产物和审批事实仍可读；对话框明确显示“连接不可用”，绝不回退到旧 POST /api/agent/tasks。
